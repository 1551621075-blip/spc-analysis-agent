# 验收记录

本页区分实际运行、TEST 提供器和未覆盖范围。全量数字来自一次完整运行，不将子模块测试数相加；失败记录保留在仓库外，不用模拟结果替代真实模型、浏览器或安装结果。

## 证据分类

- **确定性统计测试**：使用原创合成测量和独立公式/边界反例核验算法，不是生产数据验证。
- **TEST 链路**：真实数据库、统计、接口和状态机，但调查由 SyntheticProvider 返回明确测试动作，没有大模型推理。
- **真实模型链路**：实际本地 Qwen 生成工具选择和草稿；输入仍是原创合成测量。与现场因果/设备执行无关。
- **浏览器链路**：真实 Chrome、新隔离 profile、TEST 模式服务，不读取用户实际浏览器数据。
- **包与发布**：实际构建、源码外安装及远端逐 blob 对比；不等同于渗透测试、供应链担保或法律审计。

## 已记录的集成失败及修正

1. 第一轮完整 TEST 验收在九类统计场景、调查和措施执行确认后，访问缺失的 `followup` 合成样本失败（`KeyError: 'followup'`）。整轮记为失败，原记录保留。修正方向是补充独立采样、时间真正后移的稳定数据，不复制风险测量改时间充当随访。
2. 统计语义 `baseline_hash` 与人工审核外层 `content_hash` 曾混用，引起集成哈希不一致。二者已区分：评估/风险/随访绑定统计语义哈希，人工批准绑定完整文档哈希；组合回归已通过。
3. Pydantic 的 `Literal[True]` 在 `strict=True` 下仍接受 `1` 和 `1.0`。已加执行确认/无结果对账的前置验证，只接受真正布尔 `true`；严格 schema 回归 53 项通过。这不是全量测试数字。
4. 模型调用记账和异常路径已通过定向回归：调用中撤权不免除已知 token 记账；发送前明确失败不记未知用量；数据库回滚同步恢复 Python 状态；工具写盘之后重新检查累计合作式时间。
5. 首次真实 Qwen 验收在第一个调用未得到可用响应，193.242 秒后整体失败；调用保留 `unknown`、`tokens: null`，调查为 `blocked`，没有执行工具或自动重试。6,621 字节的调用上下文包含大量重叠规则窗口。后续优化只改变模型输入投影：按 chart/rule/side 汇总**全部**命中次数和首末索引，并保留完整分析哈希及投影说明；冻结统计、全部原始窗口、后端规则和预算不变。该优化之后的新目录复验另行记录，不覆盖第一轮失败。

6. 实际 Chrome 首次在基线审批下拉框发现“批准”选项缺失。HTML 将开标签误写成 `</option value="approved">`，静态字符串检查没有捕获。修正实际模板标签、补充 HTMLParser 回归后，重新从登录跑完 24 项检查，没有绕过 UI 完成审批。
7. 实际构建后，发布检查因 `Requires-Python` 子句顺序不同而误拒绝：源码 `>=3.12,<3.13`，Hatchling 标准化为 `<3.13,>=3.12`。仅按子句排序和两端空白归一化，保留操作符、版本范围和重复子句差异；拒绝空子句，新增等价/不等价回归。修正后重新构建，wheel/sdist 源码一致性及源码外离线安装通过，未跳过发布门槛。

## 真实模型通过范围

第二轮采用实际 `Qwen3-4B-Instruct-2507-Q4_K_M.gguf`、llama.cpp b6500、Apple M1 CPU、原有 300 秒调查预算。模型在均值偏移风险上自主选择两类取证和提交，3 次回包的 total tokens 分别为 743、871、1,269，均有可靠用量且状态为 completed。报告保持权威统计和签发证据不变，草稿无权创建措施；终态重跑没有产生新调用。

脚本另行验证 9 类确定性统计场景，以及明确的人工合成措施审批/执行/新窗口随访/关单。**不是 9 次真实模型调查，也不是现场因果或设备执行验收。**真实模型草稿依然未审核，形式和引用合格不证明其每句话正确。

Chrome 155 使用全新临时 profile 与真实 TEST API，实际完成登录、人工基线审批、normal/mean_shift/variance/missing 控制图、显式调查、独立措施审批/执行声明/新数据随访/关单和审计。检查 SVG 坐标/控制限与服务端冻结统计一致，缺失子组不连线、不补零；未审核草稿与权威统计分区。退出时延迟一个真实 API 响应，确认晚回包不能恢复旧身份和对象，刷新后凭据消失。
