# SPC 分析 Agent（本地 Demo／测试版）

本仓库提供本项目的本地 Demo／测试版本，用于生产部署前在本地验证核心功能、业务流程与交互方式。

基于原创合成工艺数据开展 SPC 分析：先用确定性统计识别异常和适用性问题，再让受限本地模型取证、形成调查草稿；措施的提出、审批、执行确认、随访和关单分别留痕。

**使用范围：** 本版本使用合成数据与本地测试环境，不包含真实业务或设备数据、内部资料、生产模型及敏感配置。本地验证结果不代表生产环境的可用性、效果或业务收益。

**不接生产接口，不把合成结果当作现场验证。TEST 链路与真实本地模型验收严格区分。**

## 解决什么问题

控制图报警不等于根因，数据不可评价也不等于过程正常。本工程把统计事实、模型假设和人工措施分开，避免“看见异常 → 模型给原因 → 自动关单”的跳步。

```text
原创测量数据 → 严格数据/测量条件检查
                   ↓
25 × 5 Phase-I 数据 → 草稿基线 → 人工审核冻结
                   ↓
监控数据 → Xbar-R / Nelson 八规则 / 能力门槛
                   ↓
           冻结评估 → 去重 RiskEvent
                   ↓
       本地模型选择受限工具 → 证据绑定的未审核调查草稿
                   ↓
人工提出措施 → 审批 → 执行确认 → 新窗口随访 → 审核关单
```

SPC 统计不是 ReAct：计算顺序、公式和判定由代码决定。只有风险之后的调查是有限工具选择循环，不强加 LangGraph，不允许模型修改控制限、执行代码或直接改变措施状态。

## 已实现的核心功能

| 模块 | 行为与边界 |
|---|---|
| 冻结基线 | 恰好 25 个 n=5 子组；校验通过后形成草稿，精确哈希人工批准后才可监控 |
| Xbar-R | 控制限来自冻结基线，R 图独立检查越限；与产品规格限分离 |
| Nelson 八规则 | 严格阈值/相等/中心点边界，缺失和间断断开窗口，多条命中同时保留 |
| 能力指标 | Cp/Cpk、Pp/Ppk 只有稳定性、样本量、测量条件等满足门槛时输出；不证明分布假设成立 |
| 适用性阻断 | 缺失、混批、工况混用、乱序/重复/未来观测、MSA/校准问题等不伪装为稳定 |
| 有限调查 | 仅过程上下文、测量上下文、措施历史、提交草稿；必须有过程和测量证据，引用绑定已签发证据 |
| 措施闭环 | 精确内容审核、显式执行确认、真正新的后续数据、合格随访后才能人工关单 |
| 存储与权限 | SQLite 事务、内容寻址制品、版本/租约检查、幂等操作回执、所有者及工厂范围隔离 |
| 本地工作台 | 中文页面、SVG 控制图、能力和阻断原因、风险/调查/措施分阶段操作，不依赖外部 CDN |
| 可运行入口 | CLI、FastAPI、TEST 提供器、真实回环模型适配、仓库外托管模型配置 |

调查预算固定为 **10 次模型调用、8 次工具调用、32,000 总 token、300 秒累计合作式时间**。未知结果停止并要求管理员对账，不自动重发。合作式时间不是能够中断任意底层计算的硬实时截止。

## 快速运行

需要 Python **3.12** 和 uv。在本项目根目录：

```bash
uv sync --locked
uv run spc-analysis init ./.spc-data
uv run spc-analysis serve ./.spc-data --test-mode
```

打开 `http://127.0.0.1:8004`。用 `init` 仅显示一次的本地管理员令牌登录；不要把令牌写入源码、截图分享或提交。初始化不会自动批准基线。数据目录必须是新目录，已有目录不覆盖。

`--test-mode` 使用明确标记的 **TEST** 提供器，没有大模型推理。真实本地运行见 [运行时配置](docs/runtime.md)，不会静默切云。完整逐步操作见 [使用说明](docs/usage.md)。

## 统计口径

n=5，`d2=2.326`、`D3=0`、`D4=2.114`：

- 基线组内尺度：`sigma_within = Rbar_baseline / 2.326`。
- Xbar 标准差：`sigma_xbar = sigma_within / sqrt(5)`；控制限为基线中心 ± `3 × sigma_xbar`。
- R 控制限：`[0, 2.114 × Rbar_baseline]`。
- Cp/Cpk 使用**本次监控数据**的 `Rbar / 2.326`；Pp/Ppk 使用本次全部原始测量的样本标准差（`ddof=1`）。这不改变控制图的冻结尺度。
- 能力计算至少要求 25 个有效 n=5 子组、稳定性门槛、完整规格及单位、非零方差、有效的 MSA/校准声明；仍需现场验证合理子组、独立性、分布适用性。

MSA 和校准是输入声明及有效期检查，工程没有实际进行 Gage R&R 或校准设备。八条规则同时使用会改变整体误报行为，不承诺保持单条规则的误报率。

## 验证与发布状态

已完成九类确定性统计场景、TEST 调查与独立人工措施闭环；实际本地 Qwen 完成一次风险调查（3 次调用 / 2,883 total tokens）。真实 Chrome 的 24 项工作台检查通过，浏览器使用明确 TEST 提供器，不冒充真实模型 UI 验收。

全量回归、包安装、失败记录和各项证据范围见 [验收记录](docs/validation.md)。不把局部测试相加当作全量，也不把形式检查通过当作模型语义或现场因果验证。发布仅限已审查的原创工程，运行数据、凭据和模型不在仓库中。

本地可运行：

```bash
uv run pytest
uv run ruff check .
uv run python scripts/run_acceptance.py --data-root /absolute/path/outside-repository/new-spc-test-run --test-provider
```

验收目录必须尚不存在，失败记录不覆盖。验收中的测量、措施和人工观察都是原创合成数据；稳定随访不证明措施因果有效。
